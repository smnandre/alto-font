# Support

Start with the [documentation](docs/index.md) and
the guides for [loading](docs/font-files.md),
[writing](docs/conversion/writers.md), and [subsetting](docs/subsetting/index.md). For usage questions, bug
reports, or feature proposals, use the
[Font issue tracker](https://github.com/altophp/font/issues).

## Usage questions

Describe the result you want, the smallest complete PHP example, and where
the actual result differs. Include your PHP and ALTO Font versions, input and
output formats, and whether the problem concerns inspection, conversion, or
subsetting.

## Bug reports

Include the exception message or visible difference, font source and version,
selected text, subset options, and compression adapter when relevant. For a
rendering difference, also identify the application, operating system, and
text size. Attach the smallest reproducible input only if its license permits
sharing; otherwise provide a public source or a permitted replacement.

## Feature proposals

Explain the user task, the current limitation, and an example of the desired
input and result. Mention any workaround you have tried.

## Security reports

Report suspected vulnerabilities privately to
[security@altocoda.com](mailto:security@altocoda.com), following the ALTO PHP
coordinated disclosure policy. Do not include exploit details in a public issue.
